# daarc2d2

daarc2d2 is an independent controller for compatible Droid Depot droids. It was built by Jared Ringenberg. Try the in-app demo to explore the controls with a virtual droid.

## Downloads

Android installers will appear under [Releases](https://github.com/daarcjared/daarc2d2-releases/releases) when available.
